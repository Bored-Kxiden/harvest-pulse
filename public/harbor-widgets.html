What this is, and what it is not.

This page is HTML, so it runs anywhere you can open a file. A widget that really sits on an iOS lock screen is a WidgetKit target written in Swift, which lives outside this web app entirely. Everything visual here, the palette, the type, the six stages of the flower and the vitality maths behind the ring, is taken from Harbor's own source, so a native build is a port rather than a redesign.
